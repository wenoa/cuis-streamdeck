# Cuis for Stream Deck

## What does it do?

This plugin lets you control [Cuis Smalltalk](https://cuis.st) from your Stream Deck.

## How do I install it?

### From the Elgato Marketplace

1. Search for Cuis in the [Elgato Marketplace](https://marketplace.elgato.com).
2. Follow the installation steps.

### Manually

1. Download the `.streamDeckPlugin` file from [Releases](https://github.com/wenoa/cuis-streamdeck/releases).
2. Double-click the downloaded file.
3. Stream Deck will install the plugin automatically.
